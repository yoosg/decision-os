**기술 수준:** Next.js / FastAPI / Supabase 스택을 사용하는 풀스택 개발자. 데이터 모델 설계(공통 테이블 + 도메인 테이블 분리, Memory 테이블 개념 등)를 스스로 깊이 있게 사고함.

**언어:** 한국어로 소통 (communication_language: korean).

**작업 방식:** 
- 코칭 패스 선호 (함께 논의하며 결정)
- Fast Path도 상황에 따라 사용 (PRD는 Fast Path로 진행)
- 질문에 매우 구체적이고 깊이 있는 답변을 줌 — 사전에 많이 생각해온 경우가 많음
- 아키텍처 질문에 자체적인 설계안을 가지고 있음

**프로젝트 문서 공유 대상:** 비개발자 포함 → 공유 문서는 비기술적 독자도 읽을 수 있어야 함.
